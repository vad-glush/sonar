# План обновления до SonarQube 25.8.0.112029-community

## Текущее состояние
- **Сервер**: 10.0.21.47
- **Пользователь**: glushkovvs
- **SonarQube**: 9.9.8-community → **25.8.0.112029-community**
- **PostgreSQL**: 11.15 → **15.6** (требуется обновление)
- **Community Branch Plugin**: 1.14.0 → **25.7.0** (совместимая версия)

## Анализ совместимости

### SonarQube 25.8.0.112029-community
- **Требования к PostgreSQL**: 12+ (текущий 11.15 не поддерживается)
- **Требования к Java**: 17+ (в контейнере уже включен)
- **Размер образа**: ~1.22GB (больше чем 9.9.8)

### PostgreSQL обновление
- **Текущий**: 11.15
- **Требуемый**: 15.6 (минимальная поддерживаемая версия)
- **Риски**: Возможны проблемы совместимости данных

### Community Branch Plugin
- **Текущий**: 1.14.0
- **Совместимый**: 25.7.0 (для SonarQube 25.x)
- **Изменения**: Новый формат и возможности

## Критические моменты

### 1. PostgreSQL миграция
- PostgreSQL 11.15 → 15.6 требует миграции данных
- Необходимо тестирование совместимости
- Возможны проблемы с кодировками

### 2. SonarQube миграция
- 9.9.8 → 25.8.0 большой скачок версий
- Возможны изменения в схеме базы данных
- Необходима миграция данных SonarQube

### 3. Плагин
- Community Branch Plugin 1.14.0 → 25.7.0
- Новые возможности и изменения API

## План действий

### Этап 1: Подготовка и резервное копирование
1. Создание полной резервной копии
2. Тестирование на копии данных
3. Проверка совместимости

### Этап 2: Обновление PostgreSQL
1. Остановка SonarQube
2. Обновление PostgreSQL до 15.6
3. Проверка целостности данных

### Этап 3: Обновление SonarQube
1. Обновление до 25.8.0.112029-community
2. Миграция данных
3. Обновление плагина

### Этап 4: Тестирование
1. Проверка функциональности
2. Валидация данных
3. Тестирование плагина
