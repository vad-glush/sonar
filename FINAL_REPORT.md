## 🚀 Инструкции по использованию

### Локальное тестирование
```bash
# Запуск
./start_local.sh

# Остановка
./stop_local.sh
```

### Продакшен
```bash
# Создать директории
sudo mkdir -p /var/storage/sonarqube/{data/{data,conf,logs,extensions},db}

# Запустить
docker-compose -f docker_sonar.yml up --build -d
```

## 🔍 Проверка установки

После запуска SonarQube:
1. Проверить плагин: `docker exec sonarqube-local ls -la /opt/sonarqube/extensions/plugins/`
2. Должен быть файл: `sonarqube-community-branch-plugin-1.24.0.jar`
3. Размер: ~6.4MB
