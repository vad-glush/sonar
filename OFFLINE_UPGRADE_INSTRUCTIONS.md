# 📦 ОФЛАЙН ОБНОВЛЕНИЕ SONARQUBE

## 🎯 Решение проблемы с лимитами Docker Hub

### Проблема
```
toomanyrequests: You have reached your unauthenticated pull rate limit
```

### Решение
Используем предварительно сохраненные образы Docker.

## 📁 Файлы для передачи на сервер

### 1. Образы Docker (большие файлы)
- `sonarqube-9.9.8-community.tar` (~610MB)
- `postgres-15.6.tar` (~433MB)

### 2. Конфигурационные файлы
- `upgrade_server_offline.sh` - скрипт офлайн обновления
- `OFFLINE_UPGRADE_INSTRUCTIONS.md` - эта инструкция

## 🚀 Пошаговое выполнение на сервере

### Шаг 1: Передача файлов
```bash
# Скопируйте файлы в директорию сервера
cd /home/corp.ekassir.com/glushkovvs/Docker-compose/
```

### Шаг 2: Загрузка образов
```bash
# Загрузка SonarQube 9.9.8-community
docker load -i sonarqube-9.9.8-community.tar

# Загрузка PostgreSQL 15.6
docker load -i postgres-15.6.tar

# Проверка загруженных образов
docker images | grep -E "(sonarqube|postgres)"
```

### Шаг 3: Подготовка скрипта
```bash
# Сделать скрипт исполняемым
chmod +x upgrade_server_offline.sh
```

### Шаг 4: Запуск обновления
```bash
# Запуск офлайн обновления
./upgrade_server_offline.sh
```

## 🔍 Что делает скрипт

### Автоматические действия:
1. ✅ Проверяет наличие загруженных образов
2. ✅ Создает резервную копию текущей конфигурации
3. ✅ Останавливает текущие контейнеры
4. ✅ Создает Dockerfile с плагином 1.14.0
5. ✅ Создает обновленный docker-compose файл
6. ✅ Собирает новый образ с плагином
7. ✅ Запускает обновленные контейнеры
8. ✅ Проверяет статус после запуска

### Ручные действия:
- Передача файлов на сервер
- Загрузка образов
- Запуск скрипта

## 📊 Ожидаемый результат

### До обновления:
- SonarQube: 9.8-SNAPSHOT (кастомный образ)
- Плагин: 1.13.0
- PostgreSQL: 11.15

### После обновления:
- SonarQube: 9.9.8-community
- Плагин: 1.14.0
- PostgreSQL: 15.6

## 🛡️ Безопасность

### Резервное копирование:
- Автоматическая резервная копия docker-compose файла
- Все данные сохраняются в bind mounts
- Возможность быстрого отката

### Откат:
```bash
# Если что-то пойдет не так:
sudo docker-compose -f docker_sonar.yml down
sudo docker-compose -f docker_sonar.yml up -d
```

## ⚠️ Важные замечания

1. **Размер файлов**: Образы занимают ~1GB
2. **Время передачи**: Зависит от скорости сети
3. **Время простоя**: ~5-10 минут
4. **Совместимость**: Плагин 1.14.0 совместим с SonarQube 9.9.8
